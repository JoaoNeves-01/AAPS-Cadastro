# AAPS Cadastro

> **Projeto de extensão universitária** desenvolvido para a
> Associação Anjos e Protetores de Sorocaba (AAPS).

Sistema de cadastro para apoiar a rotina da AAPS: registro de resgates,
prontuários dos animais, triagem de adotantes e controle de doações.
O projeto parte de um levantamento AS IS / TO BE da situação atual da
associação e propõe a solução desejada.

## Sobre o projeto de extensão

- **Instituição:** UNISO
- **Curso:** Ciencia de Dados e IA
- **Autor:** João Vitor Neves
- **Organização atendida:** AAPS, Associação Anjos e Protetores de Sorocaba

O objetivo é aplicar o conteúdo do curso em uma demanda real da
comunidade, entregando uma ferramenta que a associação possa usar.

## Status

| Parte | Situação |

| Frontend (HTML/CSS) | Concluído: 5 telas de protótipo |
| Backend (API + banco de dados) | Em desenvolvimento |

## Telas do frontend

| Página | Descrição |
|---|---|
| `index.html` | Painel geral com indicadores, últimos resgates e alertas |
| `resgate.html` | Ficha digital de resgate (tablet/celular, modo offline) |
| `prontuario.html` | Prontuário do animal: saúde, linha do tempo e abas |
| `adotante.html` | Triagem de adotante com checagem automática de histórico |
| `doacoes.html` | Doações e campanhas, com origem e destino dos recursos |

## Dados e privacidade (LGPD)

Todos os nomes, CPFs e telefones exibidos são **fictícios**, usados apenas
para demonstração. Nenhum dado real de adotantes ou doadores deve ser
enviado ao repositório.
